# StudentArrivalTime

Welcome to StudentArrivalTime!

This project aims to predict the probability that certain students will show up at the Math 171 and 172 Help Sessions for a given time and day based on their previous sign-ins. The model creates t-distributions and histograms for each student’s arrival times from a Google Form. Using the function pt, the model can calculate the chance a student will come before or after a certain time, from 6 p.m. to 9 p.m.
